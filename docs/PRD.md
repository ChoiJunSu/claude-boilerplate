# PRD — Contrarian "Dumb Crowd" Trading Bot (한투 모의투자)

> 대중은 늘 틀린다는 가정 위에서, 어리석은 군중 페르소나를 Claude로 모델링하고
> 그 반대로(또는 한 발 앞서) 베팅하는 자율 트레이딩 봇.

## Problem
개인 투자자(개미)는 구조적으로 최악의 타이밍에 행동한다 — 고점에서 FOMO 매수,
저점에서 패닉 매도. 이 군중 심리를 정량화해 **체계적으로 역이용**하면 엣지가 된다.
사람이 직접 하면 자기 자신도 그 군중의 일부라 감정에 휘둘린다. → 감정 없는 자동화가 필요.

## User
한 명의 구체적 페르소나: **"손절은 못 하고 추격매수는 잘하는 나"**.
한국투자증권 계좌는 있지만 실전에 돈을 넣기 전에, 역발상 전략이 모의투자에서
유효한지 **내 개입 없이** 굴려보며 검증하고 싶은 개인 개발자.

## Core Flow (단일 해피 패스)
1. 장중(09:00–15:30 KST), 봇이 일정 주기(기본 10분)로 깨어난다.
2. 관심종목(ISA 거래 가능 국내주식·ETF) 각각의 시세/등락/거래량/최근 흐름을 한투 API로 조회.
3. 그 데이터를 **"어리석은 대중" Claude 페르소나**에게 주고 "지금 개미라면 뭘 할까"를
   추론시킨다 → `{urge, conviction, emotion}` 구조화 신호.
4. 역발상 매핑: 대중이 확신에 차 **FOMO 매수**면 우리는 **판다/피한다**, 대중이
   **패닉 매도**면 우리는 **줍는다**.
5. 리스크 룰(최대 종목 수·1회 한도·현금 하한) 통과 시 한투 모의 계좌로 시장가 주문.
6. 모든 판단·주문을 SQLite 저널에 기록. 다음 주기 반복.

## Must-have Features (v0.1)
- [ ] 한투 모의투자 OpenAPI 연동: OAuth 토큰 캐시 · 시세 · 잔고 · 현금주문(매수/매도).
- [ ] Claude 군중 페르소나 → 구조화 신호 → 역발상 의사결정 + 포지션 사이징.
- [ ] 무인 실행 루프: 장중 시간 게이팅, 주기 실행, 의사결정/체결 저널링. (`--once`, `--dry-run` 포함)

## Explicitly Out of Scope
- 실전(real) 계좌 매매 — 모의투자 도메인만. 금전 리스크 0.
- 공매도/파생/해외주식 (ISA 유니버스 = 국내 상장 주식·ETF로 한정).
- 실시간 웹소켓 체결/호가 스트리밍 — REST 폴링으로 충분.
- 백테스트 엔진, 수익률 대시보드, 웹 UI.
- 한국거래소 휴장일 캘린더 정밀 처리 (주말만 거른다; 공휴일은 알려진 한계).

## Success Signal
모의 계좌에서 봇이 며칠간 사람 개입 없이 굴러가며, 저널에 "대중 신호 → 역발상 주문"이
일관되게 쌓이고, 체결이 정상 반영된다. (수익은 검증 대상이지 v0.1의 합격 기준이 아니다.)

## Open Questions
- 군중 신호의 임계치(`conviction ≥ 60`)와 1회 매매 한도는 모의 결과를 보고 튜닝.
- 한 발 앞서기(reversal 선취)를 시세 모멘텀과 결합할지 — v0.2에서 검토.
- 모의 토큰 발급 분당 제한 → 파일 캐시로 회피 (구현됨).
